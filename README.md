# 🚀 Complete 250 Data Structures & Algorithms (DSA) Roadmap in Java

Welcome to the clean, production-grade DSA practice repository. Contains **250 curated questions and answers with optimal Java implementations** covering the standard topics required for modern coding interviews.

## 📂 Repository Structure

The code is organized into 8 directories matching major DSA concepts:
1. `FoundationalConcepts/` - Complexity, Recursion, Bitwise math, Generics & Collections
2. `LinearDataStructures/` - Arrays, Lists, Strings, Custom Stack & Queue structures
3. `NonLinearDataStructures/` - Trees, Heaps, AVL, Custom Hash structures, Segment & Fenwick Trees
4. `SortingAlgorithms/` - Bubble, Selection, Insertion, Merge, Quick, Heap, Counting, Radix sorts
5. `SearchingAlgorithms/` - Linear, Binary, Ternary search variations
6. `AlgorithmDesignParadigms/` - Divide and Conquer, Greedy, Backtracking, Dynamic Programming
7. `GraphAlgorithms/` - BFS, DFS, Dijkstra, Bellman-Ford, TopSort, Cycle Detection
8. `CommonCodingPatterns/` - Sliding Window, Two Pointers, Fast & Slow pointers, Top K elements
